## 📂 Projeto em destaque

### [Gestão de Doações](https://github.com/tai05s/gestao-de-doacoes)

Aplicação web para registrar doações de alimentos, roupas e itens de higiene, acompanhar o estoque e consultar indicadores.

**Funcionalidades:**
- Cadastro e edição de arrecadações.
- Registro de baixas, exclusão e filtros.
- Exportação de dados em CSV.
- Indicadores e gráficos de estoque e validade.

**Tecnologias utilizadas no projeto:** JavaScript, Firebase Authentication, Cloud Firestore e Chart.js.
